# Salário Justo

Aplicativo web (HTML, CSS e JavaScript puros) que explica o holerite de forma clara: vencimentos, descontos, horas extras e simuladores de rescisão, férias e reajuste.

- Responsivo: celulares, tablets e computadores
- Modo claro e escuro
- Sem dependências nem etapa de build (só a fonte Manrope, via Google Fonts)

## Como usar

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

1. No repositório, vá em **Settings > Pages**.
2. Em **Branch**, escolha `main` e a pasta `/ (root)`.
3. Salve. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Aviso

Os valores são estimativas baseadas nas tabelas de INSS e IRRF de 2024. Confirme sempre com o RH da empresa.
